Overview
This project predicts students' exam scores (Exam_Score) from behavioural, family and school-related factors such as study hours, attendance, parental involvement, peer influence and teacher quality. It is a regression problem, and two models are compared: an interpretable Linear Regression baseline and a non-linear Random Forest.
The notebook is the complete, reproducible code for the project. It runs top to bottom:
imports → data loading → cleaning → preprocessing / feature engineering → EDA → visualisation → statistical analysis → model training → model evaluation → saving the cleaned dataset.
The accompanying PDF report (febin_thomas_Capstone_2026.pdf) tells the full analytical story with interpretation, limitations and recommendations. The notebook is the computational record behind it.

Methodology
1. Data loading and inspection. Shape, column types, missing values and duplicate rows are checked.
2. Data cleaning
Missing values in Teacher_Quality, Parental_Education_Level and Distance_from_Home (all under 1.4% of rows) are imputed with the column mode.
No duplicate rows were found.
Outliers are checked with the IQR method. Genuine extreme study or tutoring behaviour is kept. Only impossible Exam_Score values above 100 are capped at 100.
3. Preprocessing and feature engineering
Ordinal encoding (Low = 1, Medium = 2, High = 3) for ordered categories.
One-hot encoding (drop_first=True) for nominal categories.
Engineered features:
Engagement_Index: hours studied + attendance / 10 + tutoring sessions × 2
Study_Sleep_Ratio: hours studied ÷ sleep hours
High_Attendance: 1 if attendance is at or above the median, else 0
4. Exploratory data analysis and statistics. Correlations with the target, group comparisons (for example by parental involvement and peer influence), and descriptive statistics including skewness.

6. Modelling
Target: Exam_Score (continuous).
Split: 80/20 train-test with random_state=42.
Scaling: StandardScaler fitted on the training set only, to avoid leakage, and applied to Linear Regression. Random Forest uses unscaled features.
Models: LinearRegression and RandomForestRegressor (n_estimators=300, max_depth=8).
7. Evaluation. MAE, MSE, RMSE and R² on both train and test sets, to check for overfitting or underfitting. Feature influence is read from Linear Regression coefficients and Random Forest importances.
Key Findings
Linear Regression outperforms Random Forest on the test set (higher R², lower RMSE) and has a much smaller train/test gap, which suggests the underlying relationships are close to linear.
Attendance and the engineered Engagement_Index are the strongest predictors of Exam_Score in both models, consistent with the EDA correlation results.
